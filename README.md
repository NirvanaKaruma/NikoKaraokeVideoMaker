# NikoKaraokeVideoMaker

KTV 字幕底视频生成器（Windows 桌面应用）：输入歌曲名、作者、封面图与音频，一键生成带实时频谱可视化的 16:9 MP4 视频。

## 使用方法

### 下载与运行

应用交付为 Windows 可执行文件，**目标机器无需安装 Node.js**：

- **便携版**（推荐）：下载后双击即用，免安装；
- **安装版**：NSIS 安装包，可自定义安装目录，安装后开始菜单/桌面快捷方式。

> 应用**不捆绑 ffmpeg**：首次使用时按提示一键下载托管版，或指定本机已有的 ffmpeg.exe（设置 → ffmpeg）。

### 三步做出一个视频

1. 打开应用 → 左栏「素材与画面」：拖入**封面**（png/jpg/webp，支持透明）与**音频**（mp3/wav/flac/m4a；也支持 mp4/mov/webm 视频取音轨），输入歌曲名与作者；
2. 点击「▶ 播放」预览；在「文本样式」「音频可视化」等 tab 调整样式，点选画布元素可拖动位置；
3. 右上角「**导出**」→ 选择分辨率（720p / 1080p / 2K / 4K）与帧率（30 / 60）→ 开始导出，等待完成。

### 检查更新

应用内置自更新（设置 → 关于 → 检查更新）：从 GitHub Releases 检测新版本，下载便携版（SHA-256 校验）后自动替换重启。

### 常用快捷键

| 快捷键 | 功能 |
| ------ | ---- |
| Space | 播放 / 暂停预览 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 |
| Ctrl+S | 保存工程 |
| Ctrl+E | 打开导出 |

> 全部快捷键可在「设置 → 快捷键」中改绑。

## 软件功能与特性

- **时间轴编辑**：多片段编排、关键帧动画（位置/缩放/透明度/颜色等 30+ 属性）、片段间转场（淡入淡出/曲线过渡）；
- **音频可视化**：实时频谱柱（分带/形态/颜色/灵敏度可调）、手动节拍源（BPM 或周期）、踩点脉冲与粒子爆发；
- **动效系统**：Ken Burns 运镜、呼吸/旋转/发光、文本入场（打字机/滑动/弹跳）、全局后期（暗角/颗粒/扫描线/光漏）；
- **音频工程**：前导留白、淡入淡出（KTV 场景）；
- **精确渲染**：预览与导出同源渲染（所见即所得）；WebCodecs H.264 编码（自动选择 GPU/CPU），ffmpeg 无损混流；
- **工程保存**：项目文件含封面/背景内嵌与完整布局，支持撤销/重做（100 步）与定期自动保存；
- **多语言**：简体中文 / English / 日本語。

## 从源码构建（开发者）

```bash
# 安装依赖（国内网络已配置 npmmirror 镜像）
npm install

# 开发模式（热重载）
npm run dev

# 打包 Windows 可执行文件（安装版 + 便携版）
npm run build:win
```
